#Projeto Ilumina-o Inteligente#
1. Sobre o projeto

O Projeto Ilumina-o Inteligente consiste no desenvolvimento de uma solução de iluminação inteligente que integra hardware e software. O projeto utiliza um programa desenvolvido para Arduino, uma aplicação em Python e uma página web em HTML, com o objetivo de integrar os componentes envolvidos no funcionamento do sistema.

Este repositório reúne os códigos-fonte desenvolvidos durante a implementação do projeto, permitindo a consulta da estrutura de software utilizada.

2. Tecnologias utilizadas
Arduino IDE: desenvolvimento e programação do código embarcado.
Python: execução da aplicação responsável pelas funcionalidades implementadas no arquivo Python.
HTML: estruturação da página web do projeto.
GitHub: armazenamento e disponibilização dos códigos-fonte.
3. Estrutura do repositório
Projeto-Ilumina-o-inteligente/
├── Projeto do Arduino.ino
├── Configuração do site.html
├── Rodar valores do Arduino.py
└── README.md

4. Descrição dos arquivos
Projeto do Arduino.ino: contém o código desenvolvido para o Arduino IDE.
Configuração do site.html: contém a estrutura HTML da interface web do projeto.
Rodar valores do Arduino.py: contém o código Python desenvolvido para as funcionalidades da aplicação.
5. Como acessar os códigos

Os arquivos estão disponíveis diretamente neste repositório. Para consultá-los, basta selecionar o arquivo desejado na página inicial do GitHub.

Para executar o projeto, é necessário verificar os requisitos de hardware, as bibliotecas utilizadas e as dependências de software correspondentes a cada código.

6. Objetivo acadêmico

Este repositório foi criado para documentar e disponibilizar os códigos-fonte desenvolvidos no âmbito do projeto, facilitando sua consulta, análise e avaliação.

7. Autor

Projeto desenvolvido para fins acadêmicos.
